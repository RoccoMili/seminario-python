## Instrucciones de instalación y ejecución

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/RoccoMili/seminario-python.git
   cd seminario-python
   cd "Prácticos/Práctico 02"
   ```
2. **Crear y activar un entorno virtual:**
   - En Windows
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   ```
   - En Linux/macOS
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
3. **Instalar Jupyter:**
   Usando pip:
   ```bash
   pip install jupyter
   ```
4. **Iniciar Jupyter:**
   Desde la raíz del proyecto, iniciar el servidor de Jupyter:
   ```bash
   jupyter notebook
   ```
